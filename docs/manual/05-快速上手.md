# 05 · 快速上手（5 分钟跑通）

> 目标：从一份空白 Word 模板，到拿到第一份 PDF。全程约 5 分钟。
> 本地默认地址：`http://localhost:18100`（以部署方实际地址为准）

---

## 第 0 步：登录

浏览器打开 `http://localhost:18100`，用管理员分配的账号登录。首次使用会进入新手引导，可随时在「引导与帮助」页重新播放。

## 第 1 步：下载空白模板（1 分钟）

进入 **引导与帮助**（`/help`），点右上角「**下载空白示例模板**」，拿到 `blank-template.docx`。

或者直接用内置的「代码审计报告」模板（`audit-report`）试跑，不用自己做模板——跳到第 4 步。

## 第 2 步：在 Word 里写几个占位符（2 分钟）

用 Word 打开空白模板，在正文里**连续纯文本**敲：

```
报告名称：{{ 报告名称 }}
出具单位：{{ 出具单位 or "示例科技有限公司" }}
出具日期：{{ 出具日期 }}
```

> 记住 §3 的铁律：一次性敲完、别切字体、别加批注。保存。

## 第 3 步：上传到模板库（1 分钟）

进入 **模板中心 → 模板库**，点上传：

1. 选你刚保存的 `.docx`；
2. 填模板编号（小写字母/数字/连字符，如 `my-report`）、名称；
3. 下一步看**扫描诊断**——没有红色 error 就能确认创建；
4. 创建后系统自动识别出变量清单与示例 JSON。

## 第 4 步：投递数据拿 PDF（1 分钟）

进入 **集成中心 → 投递即生成**（或模板详情里的「接入」），填一份 JSON：

```json
{
  "报告名称": "示例报告",
  "出具单位": "示例科技有限公司",
  "出具日期": "2026-10-19"
}
```

选格式 `pdf`，点生成。单份小数据会**同步**返回，直接给你一条 `signed_url`，点开即下载 PDF。

或用内置模板 `audit-report`：把《01 · 模板使用手册》§7.2 那份完整 JSON 粘进去，生成即可得到一份带缺陷清单表、二维码、富文本整改建议的完整代码审计报告。
