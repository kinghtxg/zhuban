## 这是什么

铸版 ZHUBAN 是一个"Word 模板 + JSON 数据 → docx / pdf 成品"的渲染平台。你在 Word 里做好版式、留下占位符，业务系统把数据以 JSON 投递进来，平台自动替换、导出 docx 并可选转 PDF。

## 建议阅读顺序

1. 第一次用 → 先读《05 · 快速上手》跑通一遍。
2. 要做正式模板 → 精读《01 · 模板使用手册》（尤其第 2、3、4、8 章）。
3. 要接系统 → 《02 · API 调用手册》。
4. 要上签章 → 加读《03 · 签章与授权使用手册》。
5. 要做合规留痕 → 《04 · 审计日志说明》。
