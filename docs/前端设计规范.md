# docforge 前端设计规范

> 规范基线：**Arco Design** —— 字节跳动开源设计系统
> 适用范围：`web/` 全部前端代码
> 生效日期：2026-10-19

---

## 0. 为什么需要这份规范

重构前前端存在三类系统性问题，本规范逐条给出约束：

| 问题 | 重构前 | 本规范约束 |
|---|---|---|
| 色板双轨 | 自定义 `--df-text-1/2/3` 与 Arco 的 `--color-text-1/2/3` 并存，同一个灰有 3 种写法 | 颜色只认 Arco 原生变量，禁止自建色板 |
| 硬编码色值 | `#8f959e` 出现在 22 个文件、`#e5e6e8` 8 个文件 | 一律语义变量，见 §4 |
| 导航手搓 | 顶部导航是 `<button class="df-topnav-item">`、侧栏是 `<div class="df-aside-item">` | 导航只用 Arco Menu，见 §3 |

## 1. 令牌体系

令牌定义在 `src/styles/tokens.css`，**全站唯一来源**。

### 1.1 只定义了三类东西

Arco 已提供的（颜色、圆角）**不重复定义**，只做语义别名：

```
颜色      → 直接用 --color-text-1/2/3/4、--color-bg-1..5、--color-fill-1..4、--color-border-1..4
主色/状态 → --primary-6、--danger-6、--success-6、--warning-6（RGB 三元组）
圆角      → --border-radius-small(2px) / medium(4px) / large(8px)
```

本项目补充（Arco 未覆盖）：布局尺寸、间距栅格、字号阶梯、字体栈、阴影、动效。

### 1.2 语义别名（`--app-*`）

仅在 Arco 变量名业务语义不直观时使用，**值必须指向 Arco 变量**：

| 别名 | 指向 | 用途 |
|---|---|---|
| `--app-bg-page` | `var(--color-bg-2)` | 页面底色 |
| `--app-bg-panel` | `var(--color-bg-1)` | 卡片/面板 |
| `--app-bg-hover` | `var(--color-fill-1)` | hover 填充 |
| `--app-bg-selected` | `rgb(var(--primary-1))` | 菜单选中底 |
| `--app-text-title` | `var(--color-text-1)` | 标题/正文 |
| `--app-text-body` | `var(--color-text-2)` | 次要正文 |
| `--app-text-caption` | `var(--color-text-3)` | 辅助/占位 |
| `--app-text-disabled` | `var(--color-text-4)` | 禁用 |
| `--app-border` | `var(--color-border-2)` | 常规描边 |
| `--app-border-light` | `var(--color-border-1)` | 弱分隔线 |
| `--app-radius-panel` | `var(--border-radius-large)` | 卡片 8px |
| `--app-radius-control` | `var(--border-radius-medium)` | 控件 4px |
| `--app-radius-tag` | `var(--border-radius-small)` | 标签 2px |

### 1.3 ⚠️ 主色必须 `rgb()` 包裹

Arco 的主色与状态色是 **RGB 三元组**（`51,112,255`），不是完整色值：

```css
color: rgb(var(--primary-6));   /* ✅ */
color: var(--primary-6);        /* ❌ 无效 */
```

中性色（`--color-text-*` / `--color-border-*` / `--color-bg-*`）已是完整色值，可直接用。

## 2. 布局规范

### 2.1 骨架结构（Arco Layout）

```
Layout.app-shell
├── Layout.Header.app-header        56px  品牌 + 一级域导航 + 用户区
└── Layout.app-body
    ├── Layout.Sider.app-sider      220px 二级菜单（编辑器全屏模式不渲染）
    └── Layout.Content.app-content
        ├── .app-crumbbar           44px  面包屑
        └── .app-scroll                   页面滚动区
```

### 2.2 尺寸常量

| 常量 | 值 | 说明 |
|---|---|---|
| `--layout-header-height` | 56px | 顶部通栏 |
| `--layout-sider-width` | 220px | 侧栏展开 |
| `--layout-sider-width-collapsed` | 48px | 侧栏收起 |
| `--layout-crumb-height` | 44px | 面包屑条 |
| `--layout-content-padding` | 24px | 内容区左右边距 |

### 2.3 页面容器

所有页面使用 `components/PageContainer.tsx`：

```tsx
<PageContainer
  title="模板库"
  subtitle="上传 docx 模板，自动扫描占位符"
  extra={<Button type="primary">上传模板</Button>}
>
  {/* 内容 */}
</PageContainer>
```

- 主操作区**一律在标题右侧**，全站统一（不出现"有时在上方、有时在下方"）
- 内容区边距 20px 24px
- 既有手写 `.df-page` 页面可渐进迁移，样式已对齐 token

## 3. 导航规范

### 3.1 层级

| 层级 | 组件 | 位置 | 数据来源 |
|---|---|---|---|
| 一级域 | `Menu mode="horizontal"` | 顶部通栏 | `constants/nav.ts` → `DOMAINS` |
| 二级菜单 | `Menu mode="vertical"` | 左侧 Sider | `DOMAINS[].children` |
| 面包屑 | `Breadcrumb` | 内容区顶部 | 域 + 二级项 + 页面级追加 |

### 3.2 强制约束

- **禁止手写 `button` / `div` 模拟菜单项**。Arco Menu 自带键盘可访问性、选中态管理、折叠能力，手搓版本全部缺失。
- 选中态通过 `selectedKeys` 驱动，禁止用 `className` 手动拼 `active`。
- 菜单外观定制写在 `global.css` 的 `.app-nav-top` / `.app-nav-side` 作用域下，**只覆盖视觉，不覆盖行为**。
- 路由层级在 `constants/nav.ts` 单点维护，禁止在组件里硬编码路径列表。

## 4. 色彩规范

### 4.1 禁止硬编码色值

以下色值曾大规模出现，现已全部替换为语义变量，**禁止再次引入**：

| 曾出现的硬编码 | 等价变量 |
|---|---|
| `#8f959e` (22 文件) | `var(--color-text-3)` |
| `#e5e6e8` (8 文件) | `var(--color-border-2)` |
| `#c9cdd4` (5 文件) | `var(--color-border-3)` |
| `#d0d2d5` | `var(--color-text-4)` |
| `#1f2329` | `var(--color-text-1)` |
| `#3370ff` | `rgb(var(--primary-6))` |
| `#e8f0fe` | `rgb(var(--primary-1))` |
| `#f53f3f` / `#e64545` | `rgb(var(--danger-6))` |

### 4.2 允许硬编码的唯一例外

- 代码块高亮（`.df-codeblock` 的 `#282c34` / `#abb2bf`）—— 深色代码主题，与明暗主题无关
- 阴影的 rgba 分量 —— Arco 未提供 shadow token，已固化为 `--shadow-1/2/3`

### 4.3 品牌渐变

仅品牌标识（`.brand-mark`）允许使用渐变 `--brand-gradient`，其他位置禁止渐变装饰。

## 5. 字号与间距

### 5.1 字号阶梯

| Token | 值 | 用途 |
|---|---|---|
| `--font-size-display` | 24px | 登录页品牌名 |
| `--font-size-title-1` | 20px | 页面主标题 |
| `--font-size-title-2` | 18px | 抽屉/弹窗标题 |
| `--font-size-title-3` | 16px | 卡片/区块标题 |
| `--font-size-body-3` | 14px | 正文/表格/按钮（默认） |
| `--font-size-body-2` | 13px | 次要正文/侧栏菜单 |
| `--font-size-body-1` | 12px | 辅助说明/时间戳 |

字重只用 400 / 500 / 600，**标题用 600，不用 700**。

### 5.2 间距栅格（4px 基准）

`--space-1`(4) `--space-2`(8) `--space-3`(12) `--space-4`(16) `--space-5`(20)
`--space-6`(24) `--space-7`(28) `--space-8`(32) `--space-9`(36) `--space-10`(40) `--space-12`(48)

**禁止**出现 5px / 7px / 13px / 15px 等非栅格值。

## 6. 组件使用规范

| 场景 | 必须用 | 禁止 |
|---|---|---|
| 导航 | Arco `Menu` | 手写 button/div |
| 面包屑 | Arco `Breadcrumb` | 手写 span + "/" |
| 布局 | Arco `Layout` | 手写 flex 容器 |
| 页面容器 | `PageContainer` | 各自手写 `.df-page` 头 |
| 空状态 | `EmptyState` | 各页另写空态 |
| 间距 | `<Space size="medium">` | 手写 `marginRight: 8` |
| 弹窗/抽屉 | Arco `Modal` / `Drawer` | 自造浮层 |
